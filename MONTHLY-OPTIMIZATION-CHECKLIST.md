# Monthly Optimization Checklist

Run this once per month to improve growth and conversion.

## 1) Analytics Health Check

- [ ] Open GA4 Realtime and verify events are still arriving:
  - `game_click`
  - `store_click`
  - `featured_game_click`
  - `newsletter_subscribe_success`
  - `contact_inquiry_submitted`
- [ ] Compare this month vs last month for:
  - homepage sessions
  - outbound store clicks
  - newsletter conversion rate
  - contact inquiry count

## 2) Funnel Review

- [ ] Identify biggest drop-off point:
  - homepage view -> game click
  - game click -> store page visit (estimated)
  - contact page visit -> inquiry submit
- [ ] Document one hypothesis for each major drop-off.

## 3) Content & Social Update

- [ ] Publish at least one blog update or release note.
- [ ] Update featured game section if priorities changed.
- [ ] Verify Press Kit facts and links are still current.

## 4) Performance & UX Checks

- [ ] Run Lighthouse on homepage and blog-post page.
- [ ] Confirm no major regressions in LCP/CLS.
- [ ] Verify mobile layout for homepage, contact, and blog pages.

## 5) SEO Checks

- [ ] Confirm sitemap and robots are accessible on production.
- [ ] Validate one page in Rich Results Test (FAQ or BlogPosting schema).
- [ ] Spot-check social share preview for a blog post URL.

## 6) Action Plan (Required)

- [ ] Record top 3 improvements for next month.
- [ ] Assign owner and target completion date for each item.
